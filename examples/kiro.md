# 看懂 Kiro 的权限选项

打开 Kiro 聊天右下角的权限模式菜单，把鼠标停在一项的标题、说明或右侧留白处约半秒。无需点击选项，你可以先读完译文，再决定要用哪个模式。

| 菜单原文 | 指尖译浮窗 |
| --- | --- |
| Supervised | **逐项确认**。每轮编辑文件后，Kiro 都会暂停，由你接受或拒绝每一处改动。 |
| Accept file changes | **自动接受文件更改**。Kiro 创建、编辑或删除文件时会直接执行，运行命令前会先询问你。 |
| Approve for me | **替我审批**。对于规则未涵盖的操作，模型会批准它认为安全的操作，阻止它认为不安全的操作，拿不准时再问你。 |

这些译文对应 1.1.1 收录的三段完整英文。Kiro 更新菜单文案后，匹配不到的文本会交给系统翻译。

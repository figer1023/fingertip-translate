# 指尖译 🍊

在 Mac 上读英文时，把鼠标停在生词上约半秒，旁边就会浮出中文释义。看到陌生表情也可以这样查。读 Kiro 的权限菜单时，连选项里的留白都能取词，标题和说明会一起翻译。

## 下载和安装

1. 下载 [指尖译 1.1.1 安装包](https://github.com/figer1023/fingertip-translate/releases/download/v1.1.1/FingertipTranslate-1.1.1-macOS-arm64.zip)。此安装包适用于搭载 Apple 芯片、运行 macOS 26 或更高版本的 Mac。
2. 解压，把「指尖译.app」拖进「应用程序」，双击启动。运行后可以在屏幕顶部菜单栏找到它。
3. 在指尖译的使用说明里点「打开辅助功能设置」，在「隐私与安全性 → 辅助功能」里打开「指尖译」。如果列表里没有它，点 `＋`，从「应用程序」选取它。
4. 要翻译整句，在指尖译菜单里点「准备整句翻译…」，按提示下载 Apple 的英语与简体中文语言包。常用单词和表情随软件附带，可离线查询。

发行包使用本地临时签名，未经 Apple 公证。若 macOS 提示无法验证开发者，确认下载来源后，可在「系统设置 → 隐私与安全性」找到刚才被阻止的应用，选择「仍要打开」。更新后如果悬停失效，可在「辅助功能」列表移除旧的「指尖译」，重新添加「应用程序」中的新版，随后重启指尖译。

## 现在就试一下

| 在哪里试 | 怎么做 | 会看到什么 |
| --- | --- | --- |
| 单词 `apple` | 将鼠标停在字母上约半秒 | 词典释义中包含「苹果」 |
| 表情 🍊 | 鼠标停在表情上 | 「橘子」 |
| 句子 `I like oranges.` | 拖动选中整句后松开鼠标 | 例如「我喜欢橘子。」 |
| Kiro 聊天右下角的权限菜单 | 展开菜单，把鼠标停在 `Approve for me` 选项内的留白处 | 「替我审批」，并显示完整说明，末尾是「拿不准时再问你。」 |

也可以双击 [试用页](examples/try-it.html) 在本地练习，或在菜单栏打开「试用取词…」。使用例子详见 [Kiro 菜单示例](examples/kiro.md)。

## 取词范围与权限

悬停和划词通过 macOS 辅助功能读取应用提供的文本。整项悬停适用于能提供菜单项或列表项信息的界面。图片里的英文可在菜单中开启「识别图片里的英文」，这一功能需要屏幕录制权限，用于识别指针附近的英文单词。普通取词无需开启图片识别。词典和表情查询在本机完成，整句翻译使用 Apple 翻译框架。

## 从源码构建

在 Apple 芯片 Mac 上安装带 macOS 26 SDK 的 Xcode 或命令行工具，在项目目录运行以下命令。目标路径需尚不存在。

```sh
./build.sh "$PWD/指尖译.app"
"$PWD/指尖译.app/Contents/MacOS/FingertipTranslate" --verify
```

英文词库与表情名称随附原始许可，分别见 [ECDICT 许可](Resources/ECDICT-LICENSE.txt) 和 [Unicode 许可](Resources/CLDR-LICENSE.txt)。
